# Everyday Reading Lab

Ready-to-deploy static website (no dependencies, no server).

1. Create a NEW GitHub repository, e.g. `everyday-reading-lab`, separate from other KidsTracing projects.
2. Extract the ZIP. Upload the `public` folder (keeping its contents inside that folder). Also upload this README if desired. Commit.
3. In Render: New > Static Site; connect this repository and select its default branch. Build command: `echo Static site ready`. Publish directory: `public`. Create Static Site.
4. When the live URL is assigned, update canonical URLs and sitemap.xml with that exact URL and add the Google and Bing verification meta tags inside `public/index.html` head. Redeploy. No guessed domain is included in the initial package.

All supplied SVG graphics are original instructional diagrams. The site includes three print-ready HTML activities, four guides, and basic privacy/contact pages. Links to KidsTracing are explicitly identified as companion project resources.
